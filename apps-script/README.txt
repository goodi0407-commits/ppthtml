중추신경퀴즈 결과 제출 연결 안내

현재 상태
학생 이름 입력, 30문항 완료 후 제출 버튼, 점수 및 오답 기록 코드가 준비되었다.
Google Apps Script 웹앱을 배포한 뒤 주소를 연결해야 온라인 제출이 작동한다.
연결 전에는 결과 제출 버튼이 비활성화되며 결과 파일 저장을 사용할 수 있다.

결과 확인용 시트
결과 시트 주소는 선생님께 개인적으로 안내한다.
이 시트를 학생에게 공유할 필요는 없다. 공유 범위는 제한됨으로 유지한다.

처음 한 번 설정
1. 위 결과 시트를 본인 구글 계정으로 연다.
2. 상단 확장 프로그램 메뉴에서 Apps Script를 연다.
3. Code.gs의 기본 내용을 지우고 같은 저장소 apps-script/Code.gs의 전체 내용을 붙여 넣는다.
코드 주소: https://github.com/goodi0407-commits/ppthtml/blob/main/apps-script/Code.gs
4. 저장한 뒤 상단 함수 선택 메뉴에서 setupResultsSheet를 선택하고 실행한다. 본인이 만든 코드의 권한을 확인하여 승인한다. 이후 배포, 새 배포를 선택한다.
5. 배포 유형은 웹 앱, 실행 사용자 항목은 나, 액세스 권한은 모든 사용자로 선택한다.
학교 계정 정책으로 모든 사용자 선택이 불가능하면 관리자 정책을 확인해야 한다.
6. Google이 요청하는 권한을 확인하고 본인이 만든 이 코드에 대해 승인한 다음 배포한다.
7. 표시된 웹 앱 URL 중 /exec로 끝나는 주소를 복사하여 이 대화에 알려 준다. 비밀번호나 인증 코드는 보내지 않는다.
8. 내가 cns_submission_config.json의 endpoint에 그 주소를 연결하고 배포한 뒤 시험 제출을 확인한다.

학생 사용 방법
이름만 입력하고 문제를 푼다. 정답 확인 직후 해설과 효과음을 확인할 수 있다.
30문항을 모두 채점하면 선생님께 결과 제출을 누른다.
선생님께 결과가 저장되었습니다라는 확인 문구가 나와야 제출 완료이다.
연결 실패 시 다시 제출할 수 있으며, 같은 제출 ID는 중복 저장하지 않는다.
결과 파일 저장은 개인 기기에 텍스트로 저장할 뿐 선생님께 제출하는 기능이 아니다.
이름만으로 수집하므로 동명이인이 있을 수 있고, 별도 본인 인증은 하지 않는다.

저장 내용
제출 시각(한국 시간), 학생 이름, 총점, 틀린 문항 수, 틀린 문항 번호,
틀린 문제 내용과 학생의 최초 답 및 정답, 제출 ID, 문항 버전이다.
서버에서 30개 최초 답안을 다시 채점한다. 실제 데이터는 구글 시트에만 저장한다.
GitHub 저장소에는 학생 이름과 답안을 저장하지 않는다.

문항 수정 시
웹페이지와 Code.gs의 QUESTIONS 및 QUIZ_VERSION을 함께 맞춘다.
Apps Script는 수정 후 새 버전으로 배포해야 한다.
